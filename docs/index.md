# Epixx Scripts

Resources for [Qbox](https://qbox-project.github.io/) servers, built on the ox stack. Everything here is developed in the open on [GitHub](https://github.com/Epixx1337) and supported through our [Discord](https://discord.gg/2PjtpqdQXP).

## The scripts

| Script | What it is | |
| --- | --- | --- |
| **[qbx_properties](qbx_properties/index.md)** | Player housing: apartments, shells and real MLO houses with an in-game realtor job, furniture editor, property market, rent, utilities and police raids | [GitHub](https://github.com/Epixx1337/qbx_properties) |
| **[qbx_appearance](qbx_appearance/index.md)** | Appearance system and full illenium-appearance replacement — collection-native storage, screenshot studio, tattoos, outfits | [GitHub](https://github.com/Epixx1337/qbx_appearance) |
| **[qbx_skills](qbx_skills/index.md)** | Skill tree progression: specializations, talent points, a live in-game tree editor and stat perks | [GitHub](https://github.com/Epixx1337/qbx_skills) |
| **[qbx_propplacer](qbx_propplacer/index.md)** | Scene creator: type a word, place it as a real 3D sign, light it and dress the scene with props | [GitHub](https://github.com/Epixx1337/qbx_propplacer) |
| **[qbx_core](qbx_core/index.md)** | Our build of the Qbox core with the multicharacter screen rebuilt as a NUI — scenes, layouts and portraits | [GitHub](https://github.com/Epixx1337/qbx_core) |

Each section has an **Installation** guide, an **FAQ & troubleshooting** page for the questions we actually get, and the full reference mirrored from the repository — so the deep docs here are always in sync with the code.

## Updates

Every push and release is announced in the **#updates** channel on our Discord, as a changelog with the version, what changed and — read these before updating — **⚠️ Action required** steps (new config keys, SQL files to run, dependency bumps). The *Download update* button on each changelog grabs that exact version.

## Support

- 🐞 **Bug reports** — the *bug-reports* forum on [Discord](https://discord.gg/2PjtpqdQXP). Follow the pinned template (script, version, description, steps, expected/actual, plus a screenshot or video); the bot checks it and our tooling picks the report up from there.
- 💡 **Suggestions** — the *suggestions* forum, open to everyone.
- 📖 If something in these docs is wrong or missing, that's a bug too — report it the same way.
